# BNBL Creatine Core — 제품 스펙

> 작성: 2026-06 · 상태: 기획 초안 (Draft)

---

## 1. 포지셔닝

성분이 아니라 **상태(form)와 안정성**으로 승부하는 제품.
범용 원료(예: Creapure)를 쓰더라도 BNBL의 가공·제형이 얹히면 차별화된다.

차별 2축:
1. **용해/제형** — 냉수 무침전·무이물감
2. **안정성/흡수** — 보관·용액 안정성으로 분해 최소화

이 두 축은 **체감(녹는다·안 까끌)과 신뢰(안 변한다)** 라 소비자가 즉시 느끼는 차별점.

## 2. 목표 스펙 (증명 가능한 숫자로)

| 축 | 일반 크레아틴 (대조군) | BNBL Core 목표 | 검증 방법 |
|---|---|---|---|
| **냉수 용해** | 10℃에서 침전·뜸, 잔여물 多 | 미분화/인스턴타이즈드로 **냉수 무침전·무이물감** | 탁도(NTU)·잔여물 사진 A/B |
| **입자/관능** | 까끌거림(grit) | 입도 제어(예: D90↓)로 **무그릿** | 입도분석 + 관능패널 |
| **용액 안정성** | 물에 타두면 크레아티닌 분해 | "탄 뒤 ○시간 내 분해율 ○% 이하" | HPLC 크레아티닌 정량 |
| **보관 안정성** | 습기에 굳음·분해 | 방습 제형/포장으로 흡습·분해 억제 | 가속안정성(40℃/75%RH) |

> 수치 목표는 시제품 1차 시험 후 확정. *대조군 대비 A/B 데이터 확보가 최우선 산출물.*

## 3. 클레임 안전성 가이드

- ✅ **용해성·관능·안정성** = 물리적 사실 → 자유롭게 표현 가능 ("완전 용해", "무침전", "잔여물 없음").
- ⚠️ **흡수(생체이용률) 우월성** = 인체 임상근거 필요 → 근거 확보 전까지 *"흡수 빠름" 류 보류*. 안정성→"체내 도달 전 분해 최소화" 정도의 물리화학적 논리까진 안전.
- ⚠️ 크레아틴의 **근력·운동수행 기능성 문구**는 국내 일반식품 기준상 제한 → Core는 *순도·용해·안정성으로 신뢰*를 팔고, 효능 스토리는 복합제 라인으로 확장.
- 📌 국내 표시·규제(일반식품 vs 건기식) 현행 기준은 별도 검증 필요 (TODO).

## 4. 파이프라인 상 의미

Core = **기술 쇼케이스 + 라인 공통 베이스**.
- Core의 용해/안정성 기술 → 2번(Creatine+Panax), 3번(Focus 누트로픽)에 그대로 이식.
- 복합제도 "안 굳고 잘 녹는 BNBL" 일관성 확보.

## 5. 경쟁 벤치마크 (Competitive Benchmark)

> 상세: [`../research/market-landscape.md`](../research/market-landscape.md), [`../research/competitor-comparison.md`](../research/competitor-comparison.md)

### 시장 맥락
- 크레아틴 시장 급팽창 ($4.21B by 2030, CAGR ~25%), 온라인 ~37% → DTC 전장.
- 구미 등 **편의 포맷이 폭발(검색량 +1,300%)하나 품질(함량·안정성)이 못 따라감** (구미 시험 실패율 46%).

### 경쟁제품 약점 → BNBL 직격 매핑

| 경쟁 | 강점 | 약점 | BNBL 직격 축 |
|---|---|---|---|
| Optimum Nutrition | 가성비·유통 | **컵 바닥 침전물** | ① 용해 ("끝까지 깨끗") |
| Create 등 구미 | 편의·브랜딩 | **함량 안정성 리스크** | ② 안정성 ("편한데 보증됨") |
| Thorne / Momentous | 인증·원료 신뢰 | 기술 차별 약함 | ①+② (인증 위에 기술) |
| Sports Research | 냉수 용해 강조 | 인지도 | ① 용해 (한 단계 위) |

### 도출된 차별 한 줄
