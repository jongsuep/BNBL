## 2. 약점 분석 — BNBL이 직격할 지점

### Optimum Nutrition (시장 표준)
- 압도적 가성비·유통망이나, 리뷰에서 **"컵 바닥 침전물(sediment)" 반복 지적**.
- → **BNBL 용해축 직격**: "끝까지 깨끗하게 녹는다"는 ON 대비 A/B로 시각화 가능.

### 크레아틴 구미 카테고리 (Create 포함)
- 폼팩터로 폭발했으나 **업계 전반 함량 미달·분해 이슈** (NOW Foods 시험 실패율 46%).
- Create는 Creapure+NSF로 *상위권*이나, 카테고리 전체 신뢰는 흔들림.
- → **BNBL 안정성축 직격**: "편한 포맷인데 함량·안정성까지 보증"이 빈 자리.

### 프리미엄 분말 (Thorne/Momentous)
- 신뢰는 높으나 *기술적 차별(용해·안정성)보다 인증·원료로 승부*.
- → BNBL은 **인증 + 기술(용해/안정성)** 을 결합해 한 단계 위 포지션 가능.

## 3. 포지셔닝 맵 (개념)

```
              높은 기술 차별(용해·안정성)
                        ▲
                        │      ◀ BNBL 목표 위치
                        │        (기술 + 인증)
   Sports Research ●    │
                        │   ● Momentous
   ─────────────────────┼─────────────────────▶ 높은 신뢰(원료·인증)
                        │   ● Thorne
        Create(구미) ●   │
                        │
     Optimum Nutrition ●│
                        ▼
              낮은 기술 차별
```

- 우상단(**기술 차별 × 신뢰**)은 *상대적으로 비어있음* → BNBL 목표 좌표.

## 4. BNBL 차별 한 줄 (도출)
> "프리미엄급 신뢰(원료·인증) **위에**, 끝까지 녹고 안 변하는 **기술**을 얹은 크레아틴."

- ON에는 *용해*로, 구미에는 *안정성*으로, 프리미엄 분말에는 *기술+편의*로 각각 이김.
